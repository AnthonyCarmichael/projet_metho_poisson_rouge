# Recherche sur les impacts environnementaux liés aux poissons rouges libérés en milieu naturel
## Pour que le script fonctionne, vous devez suivre les étapes suivantes:
1. Ajouter votre clé API de stadiamaps dans le fichier .env.temp et sauvegarder. Si vous n'avez pas de clé API, veuillez suivre les indications sur la documentation officielle de R : ([documentation](https://search.r-project.org/CRAN/refmans/ggmap/html/register_stadiamaps.html))
2. Renommer le fichier .env.temp pour .env
